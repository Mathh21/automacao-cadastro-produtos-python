# 🤖 Automação de Cadastro de Produtos com Python

Projeto desenvolvido para automatizar o cadastro de produtos em um sistema web utilizando uma base de dados em CSV.

## 🎯 Objetivo

Automatizar uma tarefa repetitiva de preenchimento de formulários, utilizando dados armazenados em uma planilha.

## ⚙️ Funcionamento

O programa:

- abre o navegador automaticamente;
- acessa o sistema de cadastro;
- realiza o login;
- lê os produtos de um arquivo CSV;
- percorre os registros da base;
- preenche os campos automaticamente;
- cadastra cada produto.

## 🛠️ Tecnologias

- Python
- Pandas
- PyAutoGUI

## 📂 Estrutura do projeto

- `automacao.py` → código principal da automação
- `produtos.csv` → base utilizada para os cadastros

## 💡 Conceitos praticados

- Automação de tarefas
- Manipulação de dados com Pandas
- Leitura de arquivos CSV
- Estruturas de repetição
- Condicionais
- Tratamento de valores ausentes

## ⚠️ Observação

As coordenadas utilizadas pelo PyAutoGUI podem precisar ser alteradas dependendo da resolução da tela e da posição dos elementos no navegador.

## 📌 Sobre o projeto

Este projeto demonstra a automação de um processo repetitivo de cadastro de produtos utilizando Python, Pandas e PyAutoGUI.
